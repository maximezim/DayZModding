## 2. Design decisions you should know about

1. **No custom RPCs.** The elevator and keycard use vanilla user actions. The server re-runs
   `ActionCondition` (`ActionManagerServer.StartDeliveredAction → ActionBase.Can`), and the server entry points
   re-validate everything. The client never sends a floor: commands are Up/Down/Lobby/Roof/Call/Open, and the stop
   is derived from the player's server-side position.
2. **No Paths LOD.** This departs from your spec, deliberately. DayZ infected use the runtime navmesh:
   `objectSpawnersArr` creates buildings with `ECE_UPDATEPATHGRAPH` and calls
   `ProcessMarkedObjectsForPathgraphUpdate()` (`3_game/objectspawner.c`). Bohemia's own sample building has no Paths LOD.
   AI pathing is gated in DayZDiag instead. I can add a Paths LOD if you still want one.
3. **Keycard doors can't be lockpicked.** `GetLockCompatibilityType` returns `EBuildingLockType.NONE`, and the door zone
   takes 0 damage (projectile, melee, frag). An inside **exit button** prevents trapping players. The door relocks after 60 s.
4. **Modules are stacked objects** (origin = slab top, `autocenter=0`). The core is one tall object that owns the
   elevator state, so a single entity syncs 3 variables. Floors don't know about each other.
5. **Loot on spawned buildings** needs `mapgrouppos` entries. The survey asks the engine to export them
   (`GetCEApi().ExportProxyData`) instead of computing CE orientation fields by hand.
6. **Arma Toolbox on Linux:** its extension manifest declares Windows only, so the pipeline imports and registers the
   package directly (`skygeo.load_arma_toolbox`). On Windows the same script works with the installed add-on.

## 5. Problems found / open risks

1. **Nothing has run in the engine yet.** This is the biggest risk. In particular:
   - Arma Toolbox face winding and normals as Binarize sees them
   - the keycard door swing direction
   - the elevator leaf slide direction
   - `ActionInteractBase` targeting a 28 m-tall object with a 6 × 9 m footprint
   - whether `ECE_DYNAMIC_PERSISTENCY` on spawner objects creates duplicates after a restart.

   Each of these is a line in `TESTING.md`.
2. **Unverified vanilla paths:** `dz\data\data\penetration\concrete.rvmat` and `glass.rvmat`,
   and `dz\data\data\env_land_co.paa`. `Build-SkyAssets.ps1` checks them on P: and fails loudly.
3. **Placement uses a placeholder site** (7500, 7500, Y = 0) as you chose. `sky_layout.py --strict` refuses it
   until a survey passes.
4. **Infected don't spawn on upper floors.** They spawn on terrain and walk up. The elevator does not carry AI.
   This is fine for a quiet looting experience, but it's a design point to confirm.
5. **Helicopter crash on the helipad is not used.** Tower A's roof is too small. The roof event uses vanilla supply boxes.
6. **Same loot on every office floor.** Per-floor variety needs distinct floor classes.
7. **GitHub push is still blocked (403).** Work is committed locally only; see the final message.

## 6. Recommended order for scaling (after your approval)

1. **Close the slice on Windows (1 session):**
   - run `Build-SkyAssets.ps1`, then `Build-Mod`, `Sign-Mod`, `Build-And-Run`
   - go through `TESTING.md` and the FPS protocol
   - fix the door directions and any Binarize warnings
   - lock in the budgets from real numbers

   Nothing else should scale before this.
2. **Kit generalisation in the generator:**
   - parametric floor count and stops (already in `skyspec`)
   - floor variants Apartments and Hotel (new partitions + loot groups)
   - mechanical floor
   - roofs: mechanical and garden

   This unlocks the Residential (20) and Hotel (18) towers by stacking only.
3. **Facade variants** (concrete, brick) on the existing trim sheets. Then the **Office Tower (25)**, which is also the
   first real stress test of the per-tower budgets.
4. **Interior props** (desks, cubicles, racks, vending, lockers, …) as separate P3Ds placed as proxies in the
   floor models. They have the biggest perf impact, so budget them before mass-placing.
5. **Street kit + blocks in `layout.yaml`** (roads, sidewalks, lights, traffic lights, …). Then the parking garage
   and low-rises (shops, bank, gas station).
6. **HQ landmark (35)** with the single 4K facade atlas, the skybridge, and the helicopter-crash roof event.
7. **Polish:** emissive window sets, generator-powered lights (memory `light_*` points already exist), elevator
   hum/ding sounds, and decals.
