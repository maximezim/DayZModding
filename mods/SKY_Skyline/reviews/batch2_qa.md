### 2.4 Batch-2 asset details
- Decal configs (`sky_street/config.cpp`): `Land_SKY_Decal_Dirt`, `_Cracks` and `_Graffiti` are scope 1,
  plus `_Graffiti_A..D` (inherit scope 1). Each variant uses `hiddenSelections[] = {"camo"}`.
  `model.cfg` has `class sky_decal_graffiti { sections[] = {"camo"}; }`. `camo` exists in Res 0/1/2 of
  `sky_decal_graffiti.p3d`. PASS.
- Decal P3Ds: Res 0/1/2 only, 1 quad each, no Geometry/Fire/View LOD (by design, D16 and PENDING B1).
- Decal rvmats: graffiti and cracks use `renderFlags[] = {"AlphaTest32"}` (D15 flag). Dirt has no flag, so it is
  alpha-blended (as in skyspec). Alpha statistics:
  - graffiti a-d: 70-77 % zero, 23-30 % full, <= 0.7 % partial. Nothing touches the tile border.
    The white lettering bbox stays inside x 49-469 / y 170-341 of 512, so D17 text fit PASS ("NO CURFEW" no longer clipped).
  - cracks: 99 % zero, partial alpha 230 (> 32 threshold), lines >= 2 px (perf L5).
  - dirt: 68 % partial, 26 % below 32. **Alpha is non-zero on all four borders** (top max 188/255 over
    300 px, bottom mean 107 across the full width, left and right max 113-124). See finding M1.
- Windows atlas: 4x4 cells of 256 px, opaque RGB. The same `_co` is used by `sky_windows` (emissive 0) and
  `sky_windows_lit` (`emmisive[] = {0.55, 0.48, 0.35, 1}`). Every 3rd cell is dark ("unlit"); see PENDING B4.
